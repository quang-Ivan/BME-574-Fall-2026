5. Where could this pipeline have cheated, and how do you know it did not? Name the specific line where mu and Vt were fitted, and say which rows they saw.
   - The pipeline could leak information if the mean or SVD components were fitted using test images. In Step 2, `mu = np.mean(X[train_idx], axis=0)` computes the mean from training rows only, and `np.linalg.svd(Xc, full_matrices=False)` fits the components to `Xc = X[train_idx] - mu`. Both therefore use only training rows 0–4707. Test images are projected using the same training-derived mean and components.
6. What would you need to trust this clinically? One paragraph. More subjects? Better labels? A different target? Be concrete.
   - To trust these clinically, we would want to compare our classification method to an existing gold standard, such as that of clinical radiologists. We would also want to ensure that our dataset is representative of diverse groups and diverse imaging systems, or else ensure that it is only used on individuals and systems that match our training dataset. We would also want to periodically validate its performance over time to ensure that if the population changes, the model doesn't lose performance. The last point would be to use a larger dataset and perhaps track changes in performance with training at increasing dataset sizes, to try to determine whether we've reached a plateau in diminishing returns for throwing in more data.
